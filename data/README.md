# Dữ liệu / Data

Thư mục `raw/` được giữ trống trong bản portfolio. / The portfolio ships with no raw records.

Làm theo [hướng dẫn tải dữ liệu / data-access guide](../docs/DATA_ACCESS.md) rồi đặt CSV gốc version 1 vào `raw/healthcare-dataset-stroke-data.csv`.

`.gitignore` ngăn Git thêm raw records theo cách thông thường; nó không ngăn upload thủ công qua trình duyệt. / `.gitignore` does not protect manual browser uploads.
